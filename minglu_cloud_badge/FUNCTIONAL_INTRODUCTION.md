# 1. 功能介绍

铭箓云徽章是一款云原生开发的微信小程序，集「学习管理」「打卡记录」「物品管理」「到期提醒」「奖励系统」「好友互看」等功能于一体，旨在帮助用户高效管理学习与生活。无论是个人提升、情侣互动还是好友共同进步，铭箓云徽章都能提供便捷的解决方案。

### 核心功能模块：

*   **📖 学习与打卡模块**
    *   **课程管理**：支持用户创建课程，自定义课程周期（如10天、15天、30天等），填写课程详细信息（如授课人、课程名称、简介），并能根据设置的开始时间自动计算学习周期。
    *   **学习进度与打卡**：用户可以每日进行学习打卡，系统会自动累计打卡天数。打卡成功后，将展示烟花或气球等庆祝动画，增强用户体验。用户还可以方便地查看当前课程的进度和历史打卡记录。
    *   **学习奖励系统**：系统会根据课程周期自动生成奖励规则。当用户完成阶段性学习目标后，可以解锁相应的奖励（如虚拟金额、数字徽章等）。所有奖励的发放过程都会有详细记录。
    *   **好友关联与互看**：支持用户绑定另一位用户（如情侣、好友）。绑定后，双方可以相互查看对方的学习进度和打卡状态，以此激励共同成长。
*   **📦 徽章管理模块**
    *   **徽章管理**：用户可以添加、编辑或删除徽章。在添加徽章时，可以设置徽章的分类、到期时间、提醒方式等。此外，还支持用户上传图片以生成个性化的徽章。
    *   **分类管理**：系统提供默认的徽章分类，同时也支持用户自定义分类。这有助于用户更好地管理各类徽章，如徽章申请、订阅任务等。
    *   **智能提醒**：当徽章即将到期时，系统会进行高亮提示。结合微信的订阅消息机制，还可以向用户发送到期提醒通知。
*   **✅ 通用打卡模块**
    *   用户可以随时通过日志、照片或录音等多种方式进行打卡记录与反馈。打卡成功后，同样会有庆祝动画以增强用户体验。系统还会统计并展示用户的打卡历史，方便回顾。
*   **🎉 视觉与交互体验**
    *   采用现代化设计风格，如渐变色 Banner、卡片式信息区块，并通过主色调突出重要内容。
    *   融入烟花、气球等动画庆祝组件，提升交互的趣味性。
    *   实现响应式布局，确保在主流小程序界面上都有良好的视觉适配效果。
