# Project Structure

This document outlines the directory structure and key files of the Minglu Cloud Badge WeChat Mini Program.

## Root Directory (`minglu_cloud_badge/`)

- **`miniprogram/`**: Contains all the frontend code for the Mini Program.
  - **`app.js`**: Global logic for the Mini Program (e.g., lifecycle, global data).
  - **`app.json`**: Global configuration for the Mini Program (pages, window, etc.).
  - **`app.wxss`**: Global styles for the Mini Program.
  - **`project.config.json`**: WeChat DevTools project configuration (appid, settings).
  - **`sitemap.json`**: Sitemap configuration for WeChat search.
  - **`env.js`**: (Recommended) For environment-specific configurations, like Cloud Environment ID. *(Note: This file is not yet created but is a good practice to mention).*
  - **`pages/`**: Contains all the pages of the Mini Program.
    - **`index/`**: Main landing page.
      - `index.js`
      - `index.json`
      - `index.wxml`
      - `index.wxss`
    - **`courses/`**: Pages related to Course Management.
      - **`index/`**: Course listing page. (Note: This should be `courses/index.js` etc., not `courses/index/index.js`)
        - `index.js`
        - `index.json`
        - `index.wxml`
        - `index.wxss`
      - **`create/`**: Course creation page.
        - `index.js`
        - `index.json`
        - `index.wxml`
        - `index.wxss`
    - *(Other page groups like `badges/`, `profile/`, `checkin/` will be added here as developed)*
  - **`components/`**: Contains reusable custom components. *(e.g., `weui-miniprogram/` if manually imported)*
  - **`utils/`**: Contains utility functions (e.g., date formatters, API wrappers).
  - **`images/`**: Contains static image assets.
  - **`miniprogram_npm/`**: Automatically generated by 'Build npm' command, contains npm packages like `weui-wxss`.

- **`cloudfunctions/`**: Contains all backend Cloud Functions.
  - **`courseService/`**: Cloud functions related to course management.
    - `index.js`
    - `package.json`
  - **`checkinService/`**: Cloud functions related to learning check-ins.
    - `index.js`
    - `package.json`
  - **`badgeService/`**: Cloud functions related to badge management.
    - `index.js`
    - `package.json`
  - **`generalCheckinService/`**: Cloud functions related to universal check-ins.
    - `index.js`
    - `package.json`
  - *(Other services like `userService/`, `rewardService/` will be added here as developed)*

- **`README.md`**: Main project overview and information.
- **`FUNCTIONAL_INTRODUCTION.md`**: Detailed description of the application's features.
- **`TECH_STACK.md`**: Overview of the technologies and libraries used.
- **`PROJECT_STRUCTURE.md`**: This file, detailing the project's layout.
- **`DATABASE_SCHEMA.md`**: Descriptions and structures of the Cloud Database collections.
- **`DEPLOYMENT.md`**: Instructions for setting up, configuring, and deploying the project.
- **`FEATURE_HIGHLIGHTS.md`**: Key unique selling points and interesting features of the application.
